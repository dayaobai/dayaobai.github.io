#### scp命令  
  
开发板重启首先设置ip：  
```bash
ifconfig eth0 up  
ifconfig eth0 192.168.137.4  
ifconfig  
```
  
```bash
ifconfig eth0 192.168.137.4 netmask 255.255.255.0 up  
route add default gw 192.168.137.1
```

**从虚拟机（192.168.5.2）传送文件hello (文件地址：/home/zdr/my)到开发板（192.168.5.4）的/home/test下：**  
```bash
scp hello root@192.168.5.4:/home/test  
scp recorder root@192.168.5.4:/home/test  
export LD_LIBRARY_PATH=/home/test/local/mqtt/lib:$LD_LIBRARY_PATH  
```

**从开发板（192.168.5.4）传送文件test.c (文件地址：/home/zdr/my)到的虚拟机（192.168.5.2）的/home/zdr/my/下：**  
```bash
scp /home/test/test.c zdr@192.168.5.2:/home/zdr/my/
```
