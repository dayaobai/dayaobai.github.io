./configure --host=arm-linux-gnueabihf --prefix=/home/alien/ztk/alsa-utils --with-alsa-inc-prefix=/home/alien/ztk/alsa-lib/include/ --with-alsa-prefix=/home/alien/ztk/alsa-lib/lib/ --disable-alsamixer --disable-xmlto

sudo cp bin/* /home/alien/ztk/nfs/rootfs/bin/ -rfa
sudo cp sbin/* /home/alien/ztk/nfs/rootfs/sbin/ -rfa
sudo cp share/* /home/alien/ztk/nfs/rootfs/usr/share/ -rfa

编辑arch/arm/boot/dts/Makefile ， 找 到 “ dtb-
$(CONFIG_SOC_IMX6ULL)”配置项，在此配置项中加入“imx6ull-alientek-emmc.dtb” 
**（见教程37.3.2 添加开发板对应的设备树文件）**


编辑设备树文件
```c
vi imx6ull-alientek-emmc.dts
```


编辑完成后使用如下命令
```c
make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- dtbs
```
完成后会在arch/arm/boot/dts目录下生成XXX.dtb文件，这就是要移植到开发板上的设备树文件


./configure --host=arm-linux-gnueabihf --prefix=/home/alien/ztk/qt/tslib2/tslib2222222

将该文件拷贝到/home/alien/ztk/nfs目录中
```c
cp imx6ull-alientek-emmc.dtb /home/alien/ztk/nfs
```

然后重启开发板，通过NFS命令下载对应的设备树
