将uboot下载到SD卡中，设置开发板启动模式为从SD卡中启动
（emmc不太敢乱动）

[将文件下载到SD中](将文件下载到SD中)


将准备好的zImage和设备树文件放于nfs目录下



使用nfs命令将zImage和设备树文件下载到开发板DRAM中

```
nfs 80800000 192.168.10.100:home/alien/ztk/nfs/zImage
```

```
nfs 83000000 192.168.10.100:home/alien/ztk/nfs/imx6ull-14x14-emmc-7-1024x600-c.dtb
```

启动！

```
bootz 80800000 - 83000000
```


设置环境变量，使得开发板启动时，可以自动从网络中下载zImage和设备树文件

```
setenv bootargs 'console=ttymxc0,115200 root=/dev/mmcblk1p2 rootwait rw'
```

```
setenv bootcmd 'nfs 80800000 192.168.10.100:/home/alien/ztk/nfs/zImage; nfs 83000000 192.168.10.100:/home/alien/ztk/nfs/imx6ull-alientek-emmc.dtb; bootz 80800000 - 83000000'
```

```
saveenv  //保存环境变量
```



加载自己的根文件系统

```
setenv bootargs console-tty1 console=ttymxc0,115200 root=/dev/nfs nfsroot=192.168.10.100:/home/alien/ztk/nfs/rootfs,proto=tcp rw ip=192.168.10.50:192.168.10.100:192.168.153.2:255.255.255.0::eth0:off
```
