冒泡排序：相邻元素挨个比较，大的往后沉，小的往前浮，像气泡一样冒上去。
选择排序：从一堆牌中挑出最小的，放到排好序的区域，再重复挑选。
插入排序：抓一张牌插到已经排好序的牌堆中，直到所有牌都插好。
快速排序：找一个基准值，比分它小的放左边，大的放右边，两边再递归。
归并排序：分成两半分别排序，再把排好序的两半合并。
堆排序：构建一个大顶堆（或小顶堆），反复取堆顶元素调整堆。
希尔排序：先粗略分组排序，再逐步细分调整，直到整体有序。
计数排序：用计数器统计每个元素的出现次数，按次数排好。
桶排序：把数据分到多个桶里，每个桶单独排序，最后合并桶。
基数排序：按个位、十位、百位……逐位排序，像身份证号的数字对比。

## 插入排序：

**直接插入排序**

**希尔排序**
希尔排序是将数据分组，将每一组进行插入排序。  
每一组排成有序后，最后整体就变有序了。

希尔排序，也称递减增量排序算法，是插入排序的一种更高效的改进版本。但希尔排序是非稳定排序算法。  
希尔排序是基于插入排序的以下两点性质而提出改进方法的：

- 插入排序在对几乎已经排好序的数据操作时，效率高，即可以达到线性排序的效率；
- 但插入排序一般来说是低效的，因为插入排序每次只能将数据移动一位；

希尔排序的基本思想是：先将整个待排序的记录序列分割成为若干子序列分别进行直接插入排序，待整个序列中的记录“基本有序”时，再对全体记录进行依次直接插入排序。


## 冒泡排序

经过多次迭代，通过相邻元素之间的比较与交换，使值较小的元素逐步从后面移到前面，值较大的元素从前面移到后面。

这个过程就像水底的气泡一样从底部向上「冒泡」到水面，这也是冒泡排序法名字的由来。

## 选择排序

先从头遍历整数组，必然能从中找出最小的一个（相同的找到第一个最小的就行），然后将其和原来第一个位置上的数进行交换，然后重新遍历数组。这次从

第二个位置上开始遍历（因为第一个位置上已经排序完成，第二个数之前都是有序区，其后是无序区，），再找出一个最小数，将其和第二个位置上的数交换。再重新重第三个数遍历，找出…… 直到我们将要从倒数第一个数遍历时排序也就结束了。

## 计数排序

**空间换时间**
它的优势在于在对一定范围内的整数排序时，它的复杂度为Ο(n+k)（其中k是整数的范围），快于任何比较排序算法。 当然这是一种牺牲空间换取时间的做法，而且当O(k)>O(n*log(n))的时候其效率反而不如基于比较的排序（基于比较的排序的时间复杂度在理论上的下限是O(n*log(n)), 如归并排序，堆排序）

#### 算法描述

- 找出待排序的数组中最大和最小的元素；
- 统计数组中每个值为i的元素出现的次数，存入数组C的第i项；
- 对所有的计数累加（从C中的第一个元素开始，每一项和前一项相加）；
- 反向填充目标数组：将每个元素i放在新数组的第C(i)项，每放一个元素就将C(i)减去1。

## 快速排序

快速排序是Hoare于1962年提出的一种二叉树结构的交换排序方法，

其基本思想为：

任取待排序元素序列中的某元素作为基准值，按照该排序码将待排序集合分割成两子序列，左子序列中所有元素均小于基准值，右子序列中所有元素均大于基准值，然后最左右子序列重复该过程，直到所有元素都排列在相应位置上为止。

![[87d74c8a7906375034e94f4ee4049408.gif]]


**hoare法：**
```
int PartSort1(int* a, int left, int right)
{
	int key = a[left];//设置关键点
	while (left < right)
	{
		while (a[right] > a[keyi])//从最右边开始找到大于关键点的坐标
		{
			--right;
		}
		//找大
		while (a[left] < a[keyi])//从左边开始找到小于key的坐标
		{
			++left;
		}
		Swap(&a[left], &a[right]);//交换
	}
	Swap(key, &a[left]);//当left相遇，就交换关键点和相遇点的值
	return left;返回相遇点的坐标
}
```

但是上面的程序还有一些缺陷：

在基准值的选择上，如果选择的基准值为恰好为最小值，会进行不必要的递归。在排序大量有序数据或者接近有序数据时，效率会比较低，甚至可能会出现程序崩溃的情况。这是因为在排序有序数据时，快速排序的递归调用次数过多，会导致栈溢出的情况。

**为了解决这些问题，这里有几种优化方法：**
取随机值做基准值
三数取中法选基准值
递归到小的子区间时，可以考虑使用插入排序

**[56. 合并区间](https://leetcode.cn/problems/merge-intervals/)**
2024.12.11
**有一个包含若干个区间的数组，合并所用重叠的区间**

先将数组进行排序，然后遍历，将满足条件的区间放入新数组。
如果当前遍历到的左区间大于新数组中的有区间，则无重叠部分，直接push进新数组
否则，更新区间再push进数组





**[57. 插入区间](https://leetcode.cn/problems/insert-interval/)**
2024.12.11
**合并区间的进阶**

**有一个区间不重叠的数组集合，定义一个插入区间[x, y]，将[x, y]插入数组集合中。若有重叠部分则合并**

同样将遍历到满足条件的区间push进新数组

然后分类讨论：
1. **遍历到的右区间小于插入区间的左区间x，在[x, y]左侧**
	插入
2. **遍历到的区间与[x, y]有重叠部分**
	有重叠时更新的是插入区间[x, y]的区间，最后再将其插入
3. **遍历到的左区间大于插入区间的右区间y，在[x, y]右侧**
	插入



**[33. 搜索旋转排序数组](https://leetcode.cn/problems/search-in-rotated-sorted-array/)**
2024.12.10
**将一个升序排列的整数数组，以其中某个下标进行旋转，得到新的数组。给定一个target，搜索其是否在新数组中，有则返回下标**

因为是升序再旋转，所以在新数组中一定有一半区间是有序的（左半或右半区间），所以我们用二分法分类讨论：
1. 左半区间有序，target在左半区间，直接二分法即可找到
2. 左半区间有序，target在右半区间，则取右半区间的左右半区间，进行判断
3. 右半区间有序，target在左半区间，则取右半区间的左右半区间，进行判断
4. 右半区间有序，target在右半区间，直接二分法即可找到
